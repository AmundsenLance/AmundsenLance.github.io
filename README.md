# Productive Value–Productive Power (PV-PP) Research

This repository is the primary public research hub for the Productive Value–Productive Power (PV-PP) research program developed by Lance Amundsen.

It provides a central index to the framework's public repositories, research projects, formal proof programs, benchmarks, papers, explanatory material, and related publications.

## Where to Start

For an accessible introduction to the research program, begin with the **PV-PP Framework Overview**.

For the current formal framework architecture, operator specifications, governance structure, and selected supporting material, use the **Productive Value–Productive Power (PV-PP) Framework Core** repository.

The **PV-PP Scalar Reduction Proof Program** and published benchmark projects are maintained in their own repositories so that each research program has a single authoritative public source.

## Repository Structure and Authority

This research hub is an index, not itself the canonical specification of the PV-PP framework.

Individual projects retain their own authority, versioning, status, and documentation. Material linked from this page may include formal framework specifications, proofs, benchmarks, applications, explanatory material, papers, and historical material. Their inclusion here does not give them identical architectural or research status.

For current PV-PP framework authority and status rules, consult the **PV-PP Framework Core** repository.

## Research Program

The public research program includes work concerning:

- Productive Value and Productive Power
- decision and interaction architecture
- viability and constrained selection
- scalar aggregation and reduction
- agent governance and runtime decision systems
- cooperation and multi-agent interaction
- applications and empirical research

Additional work remains developmental, exploratory, unpublished, or outside the scope of the public repositories.
